# 前端样式规范

## 字号层级

前端页面统一使用以下字号，不随意增加其他字号：

| 字号 | 使用场景 |
| --- | --- |
| `20px` | 页面主标题 |
| `16px` | 次标题、区块标题 |
| `14px` | 标题说明、标题下的描述信息 |
| `12px` | 正文、按钮、表单、菜单和常规交互文字 |
| `10px` | 细节说明、时间、URL 等弱辅助信息 |

通用要求：

1. 字号语义固定为：`20px` 主标题、`16px` 次标题、`14px` 标题说明、`12px` 正文、`10px` 细节说明。
2. 新增页面或组件时必须优先从以上字号中选择，不使用 `13px`、`15px`、`17px` 等中间字号。
3. 同一信息层级的字号必须保持一致，不能仅为适配局部空间随意缩小文字。
4. 使用组件库时，应通过主题配置或限定在业务页面下的样式统一字号，避免无范围的全局覆盖。
