# 数据库结构同步规范

数据库关系文档固定存放在：

```text
backend/DATABASE_SCHEMA.md
```

执行以下任一变更时，必须在同一个任务中同步更新该文档：

- 新增、删除或重命名数据表；
- 新增、删除、重命名或修改字段类型；
- 修改字段是否允许为空、默认值、唯一约束或索引；
- 新增、删除或修改主键、外键及表关系；
- 修改字典表的默认数据。

文档要求：

1. 使用 Mermaid 展示完整表关系。
2. Mermaid 类图中的字段必须按“字段名在前、字段类型在后”书写，例如 `product_id: BIGINT PK`。
3. 每张表都要提供 Markdown 字段表，至少说明字段名、类型、是否允许为空、约束和用途。
4. 关系图和字段表必须以实际 SQLAlchemy 模型为准，不允许只更新其中一处。
5. 没有数据库结构变化时，不为更新时间等无意义信息修改文档。
6. 数据库结构变更完成后，应运行相关语法检查和接口测试。
