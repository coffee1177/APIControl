# 01 网址留存：状态 1（分类后端完成）

## 本阶段完成

- 创建 `web-categories` 表，字段为 `id`、`name`、`parentId`、`floor`。
- 根分类 `floor = 1`，子分类层级由后端根据父分类自动计算。
- 实现 `/web/categories` 分类新增、查询、修改和删除接口。
- 分类代码统一位于 `backend/app/api/web/categories`，与路由层级保持一致。
- 当前限制最多两层分类。
- 支持修改父分类，并同步重新计算当前分类和后代层级。
- 阻止同级重名、父分类不存在、循环引用、超出层级和删除非空分类。
- 查询时按 `floor` 动态分组，再通过 `parentId` 逐层整理为 `children` 树。
- 树整理算法已通过四层模拟数据测试，未来开放更多层级时无需重写。
- 同步完成 `backend/DATABASE_SCHEMA.md`。
